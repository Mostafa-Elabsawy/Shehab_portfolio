Shehab-Eldien is a junior Flutter developer who likes turning an idea into an app people can actually use - smoothly, on both Android and iOS, from a single Dart codebase.

Most of the work sits at the connection between screen and server: calling RESTful APIs, shaping the JSON that comes back, and structuring it with clean OOP so the codebase stays easy to extend. Firebase handles the backend pieces that do not need reinventing, and Git keeps every change traceable.

Still early in the career, with a habit of reading the framework's source when the docs run out - and a graduation project, Smart Attendance, built to prove the habit works.
